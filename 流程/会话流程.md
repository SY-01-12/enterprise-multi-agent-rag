用户发 "请婚假要什么材料"，这个文件做的事：

  1. 敲门（验权）

  你这知识库是 0 吗？
    → 是 0：通用模式，跳过
    → 不是 0：去数据库查这个知识库存不存在、是不是你的
        不存在 → 扔一句"知识库不存在"，结束
        不是你的 → 扔一句"无权限"，结束

  2. 找座位（会话）

  你带 session_id 了吗？
    → 没带：给你新开一个会话，标题用你问题前 50 个字
    → 带了：去数据库找到这个会话，看看是不是你的
  然后把你的问题记到 MySQL（留痕）。

  3. 发桌号（SSE）

  yield "你的 session_id 是 99"
  前端收到这个立刻知道：本次对话 ID 是 99，后续追问要带上这个 ID。

  4. 叫 AI 干活（Agent）

  创建 Agent → 带工具（知识库检索 / 计算器 / 时间）
  告诉 Agent：thread_id = "99"（RedisSaver 自动把 99 号会话的历史对话拼好）
  只传你当前这句话，历史不用自己拼

  5. 一个字一个字往外蹦（流式）

  Agent 说 "请" → yield → 前端显示 "请"
  Agent 说 "婚" → yield → 前端显示 "婚"
  Agent 说 "假" → yield → 前端显示 "假"
  ...
  Agent 中间调了 search_knowledge_base 工具 → yield → 前端显示"正在检索知识库..."
  Agent 说 "需" → yield → 前端显示 "需"
  ...
  全程打字机效果。

  6. 收尾

  Agent 说完了 → yield "done" → 前端知道结束了
  把 AI 的完整回答存 MySQL（以后翻聊天记录用）
